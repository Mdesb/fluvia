# (camelCase / PascalCase / snake_case) et confrontés à cette liste.

# RÈGLE D'ENTRÉE — n'ajoute ici qu'un mot SANS AMBIGUÏTÉ.
# Beaucoup de mots s'écrivent à l'identique dans les deux langues : date, type, code, format,
# version, service, interface, message, session, total, export, role, agent, terminal, article,
# mode, support, client, public, extension, adapter, provider, journal, quota, projection,
# reference, reservation, caution, terrain, passage, badge, personnel, stock, revocation…
# Ils sont VOLONTAIREMENT absents : les signaler produirait des faux positifs sur du code
# anglais correct, et un garde-fou qui se trompe se fait désactiver.
#
# Ces jetons viennent d'un relevé de fréquence des identifiants réellement déclarés dans app/src
# au 20/08/2026 — pas d'une liste inventée.
