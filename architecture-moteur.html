Une nouvelle verticale ?

Elle démarre avec tout le moteur déjà prêt : il ne reste qu'à écrire ses règles métier spécifiques.

Le principe, en clair

même moteur, comportement piloté par config

🏦 Exemple : le prélèvement SEPA

Un seul moteur SEPA. Le même code génère le fichier de prélèvement ; c'est le régime de l'établissement qui change la forme, pas une version différente du logiciel.

Régie → + collectivité + UltmtCdtr Privé → créancier direct

🚪 Exemple : le contrôle d'accès

La règle « une sortie = une entrée » et la jauge de présence vivent dans le moteur d'accès. La piscine ne fait que configurer sa POSS par-dessus — l'anti-impayés du sport ne fait que basculer le même droit d'accès.

Piscine → POSS = config Sport → impayé = bascule
✅ Conséquence : une correction ou une amélioration du moteur profite à tous les secteurs d'un coup. Et un client multi-activités (piscine + patinoire + salle de sport) pilote tout depuis la même plateforme.
