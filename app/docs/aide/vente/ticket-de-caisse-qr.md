## Le ticket de caisse

Chaque vente encaissée produit un **ticket de caisse** (imprimé, PDF ou envoyé par e-mail) qui reprend
le détail des articles vendus, les montants, le moyen de paiement et un numéro de vente unique. Ce
ticket est la preuve d'achat du client.

## Le billet et son QR code

Pour les produits donnant droit à un passage (entrée, séance, prestation...), un **billet** est émis
avec un **QR code unique**, scanné aux points de contrôle d'accès (portique, borne, agent avec
douchette). Un QR code :

- n'est valable qu'une seule fois par droit de passage accordé (les règles d'anti-passback
  s'appliquent selon le paramétrage de l'établissement) ;
- reste lisible même hors connexion sur les bornes en **mode dégradé** (cf. article dédié) ;
- peut être régénéré en cas de perte, sans dupliquer le droit d'accès sous-jacent.

## Facture et NF525

Les opérations de caisse sont **scellées** conformément à la réglementation NF525 (inaltérabilité,
sécurisation, conservation, archivage) : aucune opération encaissée n'est modifiable après coup, seule
une contre-passation (avoir) permet une correction, elle-même tracée.
