## Notes d'ordonnancement

- **T1-T12** posent le socle générique (ressources, créneaux, récurrence, règles d'annulation, quota,
  réservation/participants) — aucune dépendance vers les stratégies de facturation.
- **T13-T18** implémentent le cœur métier (réservation, liste d'attente, annulation/no-show,
  émargement, bascule automatique) — nécessaires avant de brancher les stratégies de facturation
  (T19-T23) puisque `FacturationNoShow` doit exister.
- **T19-T23** (stratégies de facturation) peuvent être développées **en parallèle** entre elles une fois
  T19 posé (interface commune) — `T20`/`T21` sont prioritaires (réellement branchées) ; `T22`/`T23`
  peuvent glisser à un lot suivant sans bloquer la Definition of Done de ce lot **si** le produit accepte
  le statut « squelette documenté » du Risque n°1 du plan.
- **T24-T27** sont des extensions transverses (accès, jauge partageable, report récurrence, paiement
  partagé) indépendantes entre elles, à paralléliser selon les ressources dev disponibles.
- **T28-T31** referment le lot (sécurité fine, traçabilité, fixtures, non-régression).
